# Scene Lab — NeuroSymbolic AI for Scene Understanding

Static saved-results research demonstrator for Karthik Chelikani's MSc Artificial Intelligence dissertation at Oxford Brookes University.

## What this site shows
- Saved scene-graph predictions and bounding-box evidence
- Top-5 subject–predicate–object relationships
- Reviewed symbolic rule exclusions and logic inspection
- Aggregate results from the five-arm controlled development ablation

## Important scope note
This GitHub Pages site is a **saved-results demonstrator**, not live GPU inference. Uploading an image only previews it locally in the browser; it does not run PGSG.

Core development result shown in the site: the reference-rule condition reduced raw coded violations@5 from **5.60% to 2.50%** on the 200-image development study, a **55.4% relative reduction**.
